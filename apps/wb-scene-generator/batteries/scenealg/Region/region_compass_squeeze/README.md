# alg_region_compass_squeeze · 区域偏压缩

以区域自身**八个方位**（北/东北/东/东南/南/西南/西/西北）的边界锚点为受力点，对区域做局部有符号形变，效果类似"揉面团"：每个方位可独立设置力度，正数=压缩（该方位附近边界向内收缩），负数=拉伸（向外扩张），力度按距离平滑衰减；支持异形/非凸自然边界。

## 接口

| 方向 | 名称 | 类型 | 说明 |
|---|---|---|---|
| IN | `region` | grid | 输入区域（0/1 或多值，非零=前景），任意形状 |
| IN | `north`/`northeast`/`east`/`southeast`/`south`/`southwest`/`west`/`northwest` | number | 八个方位各自的力度，默认 0，范围 [-64,64]，可为小数 |
| IN | `radius` | number | 影响半径（格数），默认 10，范围 [1,128] |
| IN | `connectivity` | number | 距离场邻接方式，4 或 8，默认 8 |
| OUT | `region` | grid | 形变后的 0/1 区域，与输入同形状 |
| OUT | `delta` | grid | -1=被压缩移除，+1=被拉伸新增，0=未变化 |

## 算法要点

1. **锚点定位**：以区域重心为原点，在每个方位的单位向量上取投影最远的边界格作为该方位锚点——对非凸/异形区域也稳健，不要求凸形或矩形。
2. **净位移场**：每格的位移 = 各方位「力度 × 到锚点欧氏距离的 smoothstep 衰减权重」之和；多个方位的影响范围重叠时自然叠加过渡，避免硬边。
3. **有符号距离阈值**：前景格用"到最近背景的 BFS 距离"，背景格用"到最近前景的 BFS 距离"取负，与位移场逐格比较——距离场大于位移场则判定为前景，否则为背景。位移越大（压缩）越容易被判定为背景（内缩）；位移越负（拉伸）越容易把背景格纳入前景（外扩）。
4. **不改变数组尺寸**：全程在输入 `region` 原始 rows×cols 内运算（与 `alg_region_offset` 一致）。压缩总会生效；**拉伸受当前画布内已有背景余量限制**——若该方位本来就贴满画布边缘（没有背景格可用），拉伸会被裁掉，与 `alg_region_offset` "外扩受 bbox 限制" 同一约束。

## 复用场景

供 `templates/general/districts/RegionCompassSqueeze` 模板复合使用；也可在 Develop 内直接拼接到任意需要"局部推拉已有区域边界"的图里。

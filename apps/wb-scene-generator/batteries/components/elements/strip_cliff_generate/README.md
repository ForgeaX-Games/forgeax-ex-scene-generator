# 条状悬崖生成 (strip_cliff_generate)

在单张输入掩码区域内生成一层套一层的同心等高带，合并为一张多值网格，并内置形态学后处理。

> 本电池是 `hill_contour_generate` 2.0.0 的实现存档。两者的高度场算法完全相同，区别只在**分层输出的形状**：
>
> | 电池 | 每层的形状 | 隐藏上层后 |
> |---|---|---|
> | `strip_cliff_generate`（本电池） | **互斥条带**：层 L 只含高度恰好落在第 L 带的格子 | 该处什么都不剩，直接露到地面 |
> | `hill_contour_generate` | **实心嵌套面**：层 L 含所有高度 ≥ L 的格子 | 露出下一层的顶面（低一个悬崖高度） |
>
> 要层层退台的条状悬崖（每条台阶边缘独立成层、方便单独换材质）用本电池；要能一层层剥开的实心小山包用 `hill_contour_generate`。

> **DataTree 数据格式**：`inputGrid` / `outputGrid` 均为 `grid`（`access: item`）。本电池每次只处理单张网格，网格列表由引擎按 DataTree 自动逐张 fanout / 重组。

## 功能特点

1. **贴合输入形状**：输出的非零格集合恰好等于输入掩码的非零格集合——山峰位置、`peakRadius`、噪声频率都按掩码包围盒归一化，后处理也只在掩码内进行，绝不外溢到掩码之外的空白。
2. **严格嵌套**：等高带层间严格一层套一层，不会出现外层包含间隙或内层溢出的情况。
3. **圆度可控**：`roundness` 参数在 0~1 之间调节等高线形状，接近 1 时为圆形，接近 0 时轮廓趋向方形。
4. **有机边缘**：`noiseAmount` 参数为等高线叠加轻微 Value Noise 扰动，避免机械感。
5. **多峰支持**：`hillCount` 可放置多个峰，各自产生独立同心圈，相邻峰之间自然过渡形成鞍部。
6. **内置后处理**：自动执行孔洞填充、孤立碎块删除、空白归并，无需手动接 `grid_mask_clean` 电池。

## 适用情况

- 层层退台的条状悬崖、梯田状地形、等高线风格的地图标注
- 每条台阶需要单独成层（独立换材质 / 单独显隐 / 只在带边缘放装饰）的场合
- 不适用：需要「隐藏一层露出下一层」的实心山体（用 `hill_contour_generate`）；大规模连绵山脉（用 `mountain_contour_generate`）

## 基本使用方法

1. 将上游区域掩码（如某块可用地块）接入 `inputGrid` 端口
2. 调整 `contourLevels`（层数，建议 4~8）和 `hillCount`（峰数量，建议 1~3）
3. 调整 `roundness`（0.85 左右圆润感强）和 `noiseAmount`（0.1~0.15 自然边缘）
4. 输出的 `outputGrid`（多值网格）可直接接渲染器，或接 `grid_split_by_value` 拆分各层后接 `grid2node`（`values` 必须接 `z`，否则各层都落在同一平面）

## 输入参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| inputGrid | grid | — | 单张输入掩码网格，仅对非 0 格子生成等高带（DataTree 逐张处理） |
| contourLevels | number | 6 | 等高带层数，决定同心圈数量 |
| hillCount | number | 1 | 峰数量，多峰时自动分散放置 |
| roundness | number | 0.85 | 等高线圆度，0~1，越大越圆润 |
| peakRadius | number | 0.35 | 峰影响半径，相对掩码包围盒归一化 0~1 |
| noiseAmount | number | 0.12 | 边缘扰动量，0=完美圆形，0.2=自然边缘 |
| peakPosition | number | 0 | 峰位置（九宫格，见下方说明），0=随机 |
| minHoleSize | number | 20 | 后处理：最大孔洞面积（格子数），超过则保留 |
| minIslandSize | number | 8 | 后处理：最小岛屿面积（格子数），小于则删除 |
| seed | number | 0 | 随机种子，0 使用当前时间 |

## 输出参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| outputGrid | grid | 单张多值网格，每格写入其所属等高带层序号（1..contourLevels，外→内递增），其余为 0 |
| outputNameList | array | 网格中实际出现的各层名称清单，格式 [{id, name, type}]，name 为"悬崖层1"等 |

## 峰位置参数说明

`peakPosition` 使用九宫格数字键盘布局（1-9），对应区域内的相对位置：

```
7(左上)  8(上中)  9(右上)
4(左中)  5(正中)  6(右中)
1(左下)  2(下中)  3(右下)
```

- 九宫格相对**掩码包围盒**而非整张网格；若该位置落在掩码之外（凹形/L 形区域），自动吸附到最近的掩码格
- 设为 `0` 时每次随机产生位置（受 `seed` 控制）
- 设为 `1~9` 时，第一个峰固定在该区域，多峰时其余峰随机分散

## 算法说明

### 高度场构建

核心算法使用高斯距离场代替 FBM 噪声，确保等高线形态严格同心：

- 以 Lp 范数控制圆度，`p=lerp(1.2, 2.0, roundness)`
- 多峰使用 soft-max 融合，使最近峰获得更高权重，峰间自然产生鞍部
- 叠加低频 Value Noise 轻微扰动等高线边缘
- 对掩码内的高度做等面积重映射（分位数拉伸），使各层格子数相近

### 后处理流程

1. **合并各层** → 构建完整地图
2. **填充内部孔洞** → 面积 ≤ minHoleSize 且被单一颜色包围的空洞填充（仅掩码内）
3. **删除孤立碎块** → 面积 < minIslandSize 的非零连通域删除
4. **空白归并** → 掩码内残余空白格子并入相邻最多的层；掩码外的空白不参与，保持为 0
5. **合并多值网格** → 各层互斥，按层序号写入同一张多值网格输出

## 注意事项

1. **peakRadius 过小时**：峰范围覆盖不了整个输入区域，边缘格子可能全被归入最外层，适当调大至 0.4~0.5。
2. **hillCount 过多时**：多个峰争抢有限空间，外层等高线会相互干扰，建议每 100×100 格子区域不超过 3 个峰。
3. **noiseAmount > 0.3 时**：扰动较强，某些高度较低的峰可能产生碎块，建议同步调大 `minIslandSize`。
4. **等高带顺序**：`outputGrid` 中值 `1` 为最外层（最低），值 `contourLevels` 为最内层（最高），渲染时由外向内叠加即可获得正确视觉层次。
5. **各层互斥**：任一格只属于一个层，因此隐藏某层会在该处留下空洞、直接露到地面——这是本电池与 `hill_contour_generate` 的本质差别。

# 小山包等高线生成 (hill_contour_generate)

在单张输入掩码区域内生成圆润的小山包，多层等高线严格一层套一层呈同心状分布，每层输出为一张**实心嵌套面**，并内置形态学后处理。

> **和 `strip_cliff_generate` 的区别**：两者高度场算法完全相同，只差分层输出的形状。
>
> | 电池 | 每层的形状 | 隐藏上层后 |
> |---|---|---|
> | `hill_contour_generate`（本电池） | **实心嵌套面**：层 i 含所有高度 ≥ i 的格子 | 露出下一层顶面（低一个悬崖高度） |
> | `strip_cliff_generate` | **互斥条带**：层 i 只含高度恰好为 i 的格子 | 该处什么都不剩，直接露到地面 |
>
> 为什么要实心：一层 = 一个 scene 子节点，节点只持有自己那一层的体素。条带版的山顶层是个环，环内那片格子不属于任何上层节点，隐藏它就在山顶留个洞。

> **DataTree 数据格式**：`inputGrid` / `outputGrid` 是 `grid`（`access: item`），逐张 fanout；`outputGrids` / `outputLevels` 是 `access: list`，每层各成一个子分支。

## 功能特点

1. **每层都是完整的面**：层 i 是「所有高度 ≥ i」的实心区域，层层相叠。任一层单独显隐都不会在山体上留洞。
2. **贴合输入形状**：输出的非零格集合恰好等于输入掩码的非零格集合——山峰位置、`peakRadius`、噪声频率都按掩码包围盒归一化，后处理也只在掩码内进行，绝不外溢到掩码之外的空白。
3. **严格嵌套**：等高线层间严格一层套一层，不会出现外层包含间隙或内层溢出的情况，适合表现小山包或丘陵轮廓。
4. **圆度可控**：`roundness` 参数在 0~1 之间调节等高线形状，接近 1 时为圆形，接近 0 时轮廓趋向方形，便于匹配不同地形风格。
5. **有机边缘**：`noiseAmount` 参数为等高线叠加轻微 Value Noise 扰动，避免机械感，呈现自然地形感。
6. **多峰支持**：`hillCount` 可放置多个山包，各自产生独立同心圈，相邻山包之间自然过渡，形成鞍部。
7. **内置后处理**：自动执行孔洞填充、孤立碎块删除、空白归并，无需手动接 `grid_mask_clean` 电池。

## 适用情况

- 游戏地图中需要放置小山丘、土堆等凸起地貌
- 以等高线风格表现小型地形元素（山包、小丘、岛屿）
- 在已有区域掩码内快速叠加一层地形层次感
- 需要逐层显隐、逐层换材质，且每层都要是完整山体切片的场合
- 不适用：需要大规模山脉连绵延伸（建议用 `mountain_contour_generate`）；需要每条台阶独立成条带的退台悬崖（用 `strip_cliff_generate`）

## 基本使用方法

1. 将上游区域掩码（如某块可用地块）接入 `inputGrid` 端口
2. 调整 `contourLevels`（层数，建议 4~8）和 `hillCount`（山包数量，建议 1~3）
3. 调整 `roundness`（0.85 左右圆润感强）和 `noiseAmount`（0.1~0.15 自然边缘）
4. `outputGrids` 直接接 `grid2node.grid`、`outputLevels` 接 `grid2node.z`（**不要**再经 `grid_split_by_value`——它按值拆出的是互斥条带，正好抵消实心面）；`outputGrid`（多值网格）留给预览和 `alg_region_subtract`

## 输入参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| inputGrid | grid | — | 单张输入掩码网格，仅对非 0 格子生成等高线（DataTree 逐张处理） |
| contourLevels | number | 6 | 等高线层数，决定同心圈数量 |
| hillCount | number | 1 | 山头数量，多峰时自动分散放置 |
| roundness | number | 0.85 | 等高线圆度，0~1，越大越圆润 |
| peakRadius | number | 0.35 | 山包影响半径，相对掩码包围盒归一化 0~1 |
| noiseAmount | number | 0.12 | 边缘扰动量，0=完美圆形，0.2=自然边缘 |
| peakPosition | number | 0 | 山头位置（九宫格，见下方说明），0=随机 |
| minHoleSize | number | 20 | 后处理：最大孔洞面积（格子数），超过则保留 |
| minIslandSize | number | 8 | 后处理：最小岛屿面积（格子数），小于则删除 |
| seed | number | 0 | 随机种子，0 使用当前时间 |

## 输出参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| outputGrids | grid / **list** | 每层一张实心嵌套面：第 i 张含所有高度 ≥ i 的格子（格值 = i），逐张成独立子分支，接 `grid2node.grid` |
| outputLevels | number / **list** | 与 `outputGrids` 一一对应的层顶高度（最低层 0，每上一层 +1），接 `grid2node.z` |
| outputGrid | grid | 单张多值网格，每格写入其所属等高带层序号（1..contourLevels，外→内递增），其余为 0；预览 + 求剩余空地用 |
| outputNameList | array | 各层名称清单，格式 [{id, name, type}]，name 为"山包层1"等 |

## 山头位置参数说明

`peakPosition` 使用九宫格数字键盘布局（1-9），对应区域内的相对位置：

```
7(左上)  8(上中)  9(右上)
4(左中)  5(正中)  6(右中)
1(左下)  2(下中)  3(右下)
```

- 九宫格相对**掩码包围盒**而非整张网格；若该位置落在掩码之外（凹形/L 形区域），自动吸附到最近的掩码格
- 设为 `0` 时每次随机产生位置（受 `seed` 控制）
- 设为 `1~9` 时，第一个山头固定在该区域，多山头时其余山头随机分散

## 算法说明

### 高度场构建

核心算法使用高斯距离场代替 FBM 噪声，确保等高线形态严格同心：

- 以 Lp 范数控制圆度，`p=lerp(1.2, 2.0, roundness)`
- 多峰使用 soft-max 融合，使最近山峰获得更高权重，峰间自然产生鞍部
- 叠加低频 Value Noise 轻微扰动等高线边缘

### 后处理流程

1. **合并各层** → 构建完整地图
2. **填充内部孔洞** → 面积 ≤ minHoleSize 且被单一颜色包围的空洞填充（仅掩码内）
3. **删除孤立碎块** → 面积 < minIslandSize 的非零连通域删除
4. **空白归并** → 掩码内残余空白格子并入相邻最多的层；掩码外的空白不参与，保持为 0
5. **合并多值网格** → 各层互斥，按层序号写入同一张多值网格（`outputGrid`）
6. **累积成实心面** → 逐层取「层号 ≥ i」的格子生成 `outputGrids[i-1]`，配 `outputLevels[i-1] = i-1`；空层直接跳过，不产出空节点

## 注意事项

1. **peakRadius 过小时**：山包范围覆盖不了整个输入区域，边缘格子可能全被归入最外层，适当调大至 0.4~0.5。
2. **hillCount 过多时**：多个山包争抢有限空间，外层等高线会相互干扰，建议每 100×100 格子区域不超过 3 个山包。
3. **noiseAmount > 0.3 时**：扰动较强，某些高度较低的峰可能产生碎块，建议同步调大 `minIslandSize`。
4. **等高线顺序**：`outputGrid` 中值 `1` 为最外层（最低），值 `contourLevels` 为最内层（山顶），渲染时由外向内叠加即可获得正确视觉层次。
5. **体素量**：实心面层层叠加，体素数是条带版的两三倍（`grid2node` 未接 `zRange` 时按 `[0..z]` 生成实心柱）。这是"能一层层剥开"的必要代价，需要轻量表现时改用 `strip_cliff_generate`。

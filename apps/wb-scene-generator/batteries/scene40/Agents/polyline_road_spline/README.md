# polyline_road_spline（控制点道路样条）

把一串开放折线控制点插值成自然曲线道路，并光栅化为**纯道路掩码**。

## 算法语义

1. **解析控制点**：`points` 是 `access:list` 端口，**整组控制点一次消费**——既可以由多个 `pt2_construct` 经 `tree_merge` 汇成点集（画布上的常规接法），也可以直接给整份 `[[col,row],...]` / `[{x,y},...]` 或其 JSON 字符串（作为单个 item 传入时会自动剥掉外层包裹）；去掉连续重复点（重复点会让样条切线退化）。
2. **样条插值**：按**向心参数化**（弦长的平方根定参，点距不均时不产生硬折/过冲）解一条**C2 连续的自然三次样条**（追赶法解三对角，两端二阶导为 0）。结点处的一阶导由二阶导反推，左右两侧相同，因此整条曲线**曲率连续**——弯曲被摊到相邻段，而不是像局部 Catmull-Rom（仅 C1）那样全挤在控制点上形成折线感。样条在每个结点处恒等于该控制点，因此**曲线严格依次穿过每一个控制点**；`tension` / `roundness` 只缩放切线幅度，不改变这一性质（`tension=1` 收紧为直折线）。
   `roundness > 1` 会放大结点切线，把回折处的转弯半径拓宽（道路可小幅甩出控制点连线，接近真实道路的大半径过渡）；切线幅度按相邻段弦长的 2.5 倍夹持，防止锐角处自交成环。
3. **光栅化**：沿曲线用直径 `roadWidth` 的圆笔刷描边，落笔前按 0.5 格步长在采样点之间补插，`samplesPerSegment` 取小也不会断线；同时总是落笔最近整格，`roadWidth < 1` 时道路仍是 8-连通的单格路。
4. **接缝加固**：`reinforceJoints` 开启（默认）时，在道路换向的台阶处补格——2×2 窗口只缺 1 格、且缺口两侧的直路段至少持续 2 格时补上那一格，于是台阶两侧各补一格，接缝宽度与路面一致，不再出现两段直路只靠一格搭接的薄弱处。连续 45° 斜路每格都在错位，不算换向，因此不会被整体加粗（实测纯 45° 斜路格数 +0%，每 3 行错一格的陡坡 +25%）。只做一遍且判定基于加固前的快照，不会连锁加粗。
5. **裁剪**：`clipToFootprint` 开启（默认）时只在 `inputGrid` 非零格落笔，道路不会溢出上游区域；加固补的格同样受裁剪约束，因此 `Rest` 仍与道路严格互补。

**完全确定性**：无随机成分、无外部副作用，相同输入必得相同输出，因此本电池没有 Seed 端口。

## 为什么不复用 `river_spline`

`river_spline` 先做法线随机扰动：`numMidPoints=0` 时只保留首尾两点、丢弃全部中间控制点；`>0` 时把选中的控制点沿法线随机偏移并按 x 坐标重排，路线会跑偏且无法回折。它输出的是「基准网格 + 河流值」的叠加网格，下游 `alg_region_subtract` 拿它当减数会把整个足迹减空。本电池输出纯道路掩码，正好补上这两点。

## 端口

| 方向 | 端口 | 类型 | 默认 | 语义 |
|---|---|---|---|---|
| IN | `inputGrid` | grid/item | — | 基准网格，决定输出形状；非零格 = 可铺路足迹（**必接**） |
| IN | `points` | point2d/**list** | — | 整组控制点，**至少 2 个不重复点**；元素可为 `{x,y}` 或 `[col,row]` |
| IN | `roadWidth` | number/item | `2` | 道路宽度（格），圆笔刷直径 |
| IN | `tension` | number/item | `0` | 张力 `[0,1]`，0 保留完整样条曲率、1 为直折线 |
| IN | `roundness` | number/item | `1.3` | 切线幅度增益 `[0,2.5]`，1 = 标准自然样条，>1 拓宽回折处转弯半径 |
| IN | `samplesPerSegment` | number/item | `24` | 每两个控制点之间的样条采样数 |
| IN | `clipToFootprint` | boolean/item | `true` | 是否裁剪到 `inputGrid` 非零区 |
| IN | `reinforceJoints` | boolean/item | `true` | 是否在换向台阶处补格加固接缝 |
| IN | `fillValue` | number/item | `1` | 道路格填充值，其余格为 0 |
| OUT | `outputGrid` | grid/item | — | 与 `inputGrid` 同形状的道路掩码 |
| OUT | `cellCount` | number/item | — | 被填充的格数，`0` = 道路完全落在足迹或网格之外 |

## 限制

- `inputGrid` 为空或 `points` 不足 2 个不重复点时返回 `error`，不产出网格。
- 落在网格范围外的曲线段被静默丢弃；控制点顺序始终保留，不会像 `river_spline` 那样按 x 重排。
- 只处理单张网格；网格列表由 DataTree 引擎逐张 fanout。
- `roundness` 越大越容易甩出上游足迹，被 `clipToFootprint` 裁掉后道路可能断成两段；足迹紧贴控制点时调小。
- 平滑度上限由控制点本身决定：控制点构成近 180° 回折（zigzag）时，任何「严格穿点」的插值曲线都必须在该点急转，只能靠 `roundness` 拓宽转弯半径，无法变成大弧。想要更缓的走向要减少/移动控制点。
- `points` 必须是 `access:list`。若声明成 `access:item`，多分支的点集（`tree_merge` 的输出正是多分支/多 item）会被 dispatcher 拆成「每个点各调一次」，每次只拿到 1 个点从而恒定报错「at least 2 distinct control points」，整条链静默无产物。
